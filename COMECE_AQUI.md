# Comece por aqui

Caio, extraia o ZIP inteiro e abra a pasta **Flag_Game_Atlas** no VS Code.

No terminal dessa pasta, execute:

```bash
flutter pub get
flutter run -d chrome
```

No Windows, você também pode abrir `iniciar_windows.bat` com dois cliques.

Não precisa instalar Android Studio para jogar no Chrome. O Flutter precisa estar instalado e disponível no terminal. Este projeto aceita Flutter 3.47.7 ou superior; você pode manter a versão 3.47.7 já instalada. O arquivo `pubspec.yaml` deve aparecer na pasta em que você executar os comandos.

1. Escolha **Qual é o país?**, **Encontre a bandeira** ou **Bandeira secreta** nos cartões do menu.
2. Digite seu nome ou apelido.
3. Escolha o tempo total: 30 segundos, 1, 3 ou 5 minutos.
4. Escolha Fácil ou Difícil.
5. Selecione um continente ou o Jogo aleatório para misturar as regiões.
6. Clique em Começar partida. No modo de nomes, toque no país; no inverso, toque na bandeira; no secreto, observe o mosaico se abrir.
7. Ao final, confira o resultado e o ranking daquele modo. Cada desafio tem seus próprios recordes.

Para encerrar a execução no terminal, pressione `q`. Para rodar novamente depois, abra a pasta e execute `flutter run -d chrome`.

O README explica a organização dos arquivos, os requisitos do professor e como rodar no celular. Em `docs/APRESENTACAO.md` há um roteiro de demonstração. O código está pronto para ser enviado a um repositório seu, mas o repositório e o vídeo ainda precisam ser publicados por você para concluir a entrega da disciplina.
